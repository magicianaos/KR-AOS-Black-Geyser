# 블랙 가이저 한글패치 (KR-AOS)

**Black Geyser: Couriers of Darkness** (Steam) 비공식 한국어 패치입니다.

## 다운로드

**[최신 릴리즈 받기](https://github.com/magicianaos/KR-AOS-Black-Geyser/releases/latest)** — Assets에서 `BlackGeyser_KR_Patch_v1.0.exe`를 받으세요.

소개·설치 방법: https://kr-aos.win/games/black-geyser.html

## 설치

1. 게임을 완전히 종료합니다.
2. `BlackGeyser_KR_Patch_v1.0.exe`(한글패치 런처)를 실행하고 **[패치 설치하기]** 를 누릅니다.
3. 게임 설정 → 게임플레이 → 언어에서 **Korean**을 선택합니다.

되돌리기는 런처의 **원래대로 되돌리기** 또는 Steam "게임 파일 무결성 검사"로 합니다.

## 정보

- 대상: Steam 빌드 24022778 (게임 1.2.98 / DLC 1.0.28)
- 번역: 본편·DLC 27,756개 문장, 월드맵 지명 이미지 37개
- Tales of the Moon Cult DLC가 없어도 설치됩니다. (DLC 부분은 영어)
- Steam 정품으로 설치된 게임에서만 설치됩니다.
- 이 저장소와 릴리즈에는 게임 파일이 들어 있지 않습니다. 런처가 내 PC의 원본 파일에 번역을 적용합니다.

## 제보

오역·어색한 문장·화면 문제는 스크린샷과 함께 [KR-AOS 디스코드](https://discord.gg/7PBPCweTbR)에 올려 주세요.

비공식 팬 번역이며 게임의 저작권은 원 개발사·배급사에 있습니다.
